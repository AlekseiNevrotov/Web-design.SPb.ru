# 🌐 Web-design.SPb.ru

This repository contains the complete production-ready source code of **Web-Design.SPb** — a turnkey web design and development platform based in St. Petersburg, Russia.

While the author has been working in the professional design and digital industry since **2009**, this specific platform was launched to synthesize long-term expertise into production-ready web products. Following a strategic niche analysis and modern internet architecture limitations, the digital platform was officially archived in October 2026. The entire codebase is now completely open-source for the global developer and designer community.

## 🛠️ Tech Stack & Features
The project combines clean, high-performance UI/UX design with custom web applications and deep infrastructure automation:

*   **Frontend Architecture:** Clean semantic HTML5, adaptive CSS3, modern Vanilla JavaScript.
*   **Animation & UI FX:** Core implementation of custom **Morphing effects** and dynamic web layout transitions.
*   **Backend & Automation:** Scalable Node.js environment combined with Google App Script for seamless pipeline tasks and data processing.
*   **SEO Optimized:** Handcrafted semantic tags, high PageSpeed performance scores, and strict technical SEO optimization out of the box.

## 📂 Project Archive Structure
The codebase includes fully realized production projects and internal bespoke design applications:
*   Bespoke UI/UX landing page architectures (Figma prototypes to live code)
*   Turnkey mobile-first web platforms with dynamic CSS layout systems
*   Advanced automation scripts and Google-integrated web applications
*   Custom promotional flyer/poster engine deployments
